Controls

Stage

  • Drag any voice or the listener dot to move it
  • Hover a voice (mouse) — control panel appears next to it
  • Tap a voice (touch) — bottom panel slides in with the same controls

Per-voice (when hovered, mouse)

  • Scroll wheel — volume up / down
  • M — mute / unmute
  • ← → — swap instrument (live + numbered guitars only)

Spotlight

  • Double-click a voice — bring it to the front, dim the others (touch: use Spotlight in voice panel)
  • Double-click empty stage (or Esc) — exit spotlight

Top bar

  • Master volume / tempo / reverb wet / 3-band EQ — all live, change while playing
  • Loadout — set every guitar (incl. live) to one instrument bank at once
  • Random — scatter voices to random positions on the stage
  • Reset — restore default sliders, voice positions, volumes, and instruments

Other

  • Space — play / pause
  • ? — open / close this help
  • Esc — close any open overlay or return to the menu
